# Procédure interne — vérification avant opposition (document fictif, réservé aux conseillers)

Avant de confirmer une opposition, le conseiller vérifie l'identité du client avec trois questions de sécurité : date de naissance, adresse du dossier et montant de la dernière opération connue.

En cas de suspicion de fraude, le conseiller transmet le dossier à la cellule fraude sous le code interne CF-27 et propose le remboursement provisoire selon le barème interne.

Le conseiller ne demande jamais le code secret ni le numéro complet de la carte.
